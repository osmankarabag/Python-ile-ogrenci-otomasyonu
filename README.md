# 🎓 Python ile Öğrenci Otomasyonu

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)

Öğrenci kayıtlarını CSV dosyalarında tutan konsol tabanlı öğrenci yönetim uygulaması.

## ✨ Özellikler
- Öğrenci ekleme, güncelleme, silme
- Öğrenci arama ve listeleme
- Genel not ortalaması hesaplama
- Harç ücreti hesaplama

## ▶️ Çalıştırma
```bash
cd ogrenciotomasyonu
python main.py
```
